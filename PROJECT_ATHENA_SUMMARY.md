## 🏗️ ARCHITECTURE OVERVIEW

### Frontend (React + GSAP)
```
client/src/
├── utils/gsap-setup.js          # GSAP configuration & presets
├── services/
│   ├── notificationService.js   # Enhanced notifications
│   └── apiService.js           # API with animation triggers
├── components/
│   ├── auth/EnhancedAuthFlow.jsx    # Animated auth flow
│   └── ui/
│       ├── EnhancedActivityCard.jsx # Animated activity cards
│       └── EnhancedActivityGrid.jsx # Staggered loading grid
```

### Backend (Node.js + Express)
```
server/src/
├── routes/social.js             # Social interaction endpoints
├── controllers/
│   ├── socialController.js      # Social interactions
│   └── bookingController.js     # Enhanced booking flow
├── models/Like.js              # Like model for social features
└── app.js                      # Enhanced with social routes
```

### Deployment (Render)
```yaml
# render.yaml - Multi-service configuration
services:
  - type: web
    name: ludus-backend-athena    # Enhanced backend
  - type: static
    name: ludus-frontend-athena   # Enhanced frontend
```
