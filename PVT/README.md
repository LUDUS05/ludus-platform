# LUDUS Interactive Mockup - PVT

## Overview
This is a redesigned interactive mockup for the LUDUS platform that matches the modern mobile-first design specifications.

## Design Features

### Left Screen - Home/Discovery
- **Personalized Header**: "Hi, Jennifer!" greeting with user avatar
- **Prominent Search**: "Search for places..." with search icon
- **Icon-based Categories**: Camp, Mountains, Beach, Music, Food with hover effects
- **Top Trips Section**: Horizontally scrollable cards with scenic images
- **Price Tags**: Prominently displayed ($150, $120)
- **Location Markers**: Subtle location indicators

### Right Screen - Activity Detail
- **Hero Image**: Full-width immersive image of Jatibarang Reservoir
- **Pricing Badge**: Dark overlay with "$120/person" and "+10" indicator
- **Tab Navigation**: "Overview" and "Reviews" tabs
- **Rating Display**: "5 hours" duration and "4.8 out of 5" star rating
- **Description**: Brief activity description in readable font
- **CTA Button**: Full-width "Book now" button with arrow icon

## Design Principles
- **Visual Hierarchy**: Clear distinction between primary, secondary, and tertiary elements
- **Color Palette**: Monochromatic base with selective accent colors (blue #3b82f6)
- **Typography**: Clean, modern sans-serif fonts with good readability
- **Spacing**: Generous padding and margins for breathable layout
- **Mobile-First**: Optimized for mobile viewing with touch-friendly targets

## User Experience Features
- **Bottom Navigation**: Clear icons for main app sections
- **Social Proof**: Ratings and reviews
- **Price Transparency**: Clear pricing display
- **Progressive Disclosure**: Tabs for additional details
- **Visual Feedback**: Clear affordances and hover states
- **Navigation Arrows**: Next/Previous navigation between screens

## Technical Features
- **RTL Support**: Full Arabic language support
- **Responsive Design**: Mobile-optimized layout
- **Smooth Animations**: CSS transitions and hover effects
- **Interactive Elements**: Clickable cards, buttons, and navigation
- **Image Integration**: Unsplash images for hiking and music activities

## Images Used
- **Hiking Activity**: Mountain climbing image from Unsplash
- **Music Activity**: Concert/group activity image from Unsplash
- **Hero Image**: Jatibarang Reservoir scenic view

## Navigation
- **Screen 1**: Search & Discovery (Home)
- **Screen 2**: Activity Detail (with hero image and tabs)
- **Screen 3**: Booking Details
- **Screen 4**: Payment
- **Screen 5**: Success & Share

## Hosting
The mockup is hosted at: `http://localhost:3000/pvt`

## Files
- `ludus-interactive-mockup.html` - Main mockup file
- `README.md` - This documentation

## Usage
1. Start the web server: `npm start` in the `apps/web` directory
2. Navigate to `http://localhost:3000/pvt`
3. Interact with the mockup to test the user flow

## Browser Support
- Modern browsers with CSS Grid and Flexbox support
- Mobile browsers (iOS Safari, Chrome Mobile)
- Desktop browsers (Chrome, Firefox, Safari, Edge)
